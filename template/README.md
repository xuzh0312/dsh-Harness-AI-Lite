## 协议来源与升级

接入模板或已有项目时在此记录实际采用的模板来源、运行器与语言，以及可核对的协议基线：有正式发行版本才记录版本；否则记录来源提交，无法取得提交时记录原始模板包的校验值。无法核对时注明未核实，不把工作树改动写成发行版本。

升级前备份现有 Harness 和项目资料，按旧基线比较上游协议与本地修改，仅合并获授权的协议变更，不用干净模板覆盖用户填入的介绍、架构、路径、规则定制、计划、决策或历史资料，也不移动代码和验证材料。处理冲突并核对资料保留后，再更新所采用的协议基线。
