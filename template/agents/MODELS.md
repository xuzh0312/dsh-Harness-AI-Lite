# 子 Agent 使用约定

当前写入者：无（写入规则见 [AGENTS.md](../AGENTS.md#写入授权与验收)）

项目子 agent 约定：待确认。只在实际项目副本中记录，不预设各角色的模型和推理深度。

本约定只配置执行者、审查者的子实例。

## 首次确认

只在需要创建执行者或审查者时适用；纯问答和不派子 agent 的访谈、规划步骤不必先问。首次派工前核对当前适用的约定与用户要求。缺少有效答复时，先问：“这个项目对子 agent 的模型或推理深度有什么限制？可以限定角色或参数，其余我按任务选择。”收到答复再派工，已有适用答复直接沿用。

记录用户答复的依据和适用范围。项目级答复在获准时记入上方约定，否则保存在已有交接或只读回复中。本次任务或单个实例的限制只在指定范围生效。

换任务或会话先查本文件和交接，优先核对热路径中本功能所指的答复依据，不默认检索归档。按范围沿用仍有效的用户答复。已有部分设置即可继续派工，只有找不到适用答复、限制有歧义、互相冲突或无法满足时才问未决事项。
