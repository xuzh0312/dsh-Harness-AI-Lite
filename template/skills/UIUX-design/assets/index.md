# 可挑选的界面素材

## UI 技法图鉴

先写清任务与设计问题，再按[技能入口](../SKILL.md)结合平台和动效偏好筛选。已确认或委托的选择不重复询问。图鉴按需查阅，不作为默认风格。

| 材料 | 观察什么 | 怎么换成自己的设计 |
| --- | --- | --- |
| [布局图鉴](<UI技法图鉴/布局图鉴.html>) · [布局分类参考](<UI技法图鉴/页面布局设计全景分类参考.md>) | 页面结构、导航位置、信息层级及宽窄容器的差异。 | 用项目的真实内容比较候选布局，明确宽屏与窄屏各自如何重排。 |
| [动效与材质图鉴](<UI技法图鉴/动效与材质图鉴.html>) · [动效与风格分类参考](<UI技法图鉴/动效界面设计风格全景分类参考.md>) | 状态反馈、过渡、空间关系及视觉材质。 | 只借用能解释状态或操作的部分，检查可中断性、可读性和减少动态效果时的反馈。 |
| [工作台样板](<UI技法图鉴/工作台样板.html>) | 队列、筛选、详情、空态和失败态如何组成同一个任务。 | 用项目的实际任务和数据验证流程，不复制演示文案或配色。 |

有浏览器时可直接打开 HTML 查看对照；不便预览时，先用分类参考定位条目，再按编号读对应演示源码。引用时注明分类与编号（如「布局 3.4」）；标为「近似」或「示意」的示例不当作原生实现或项目实测证据。交接时说明参考了哪项、采用了什么、按项目改了什么。更多说明见[图鉴使用说明](<UI技法图鉴/图鉴使用说明.md>)。
