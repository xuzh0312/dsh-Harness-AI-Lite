## 一、网页整体布局模式

> 定义网页的"骨架"结构，决定页面如何组织内容。

### 1.1 单页式布局（Single Page）
- **定义**：全部内容放在一个页面内，通过锚点或滚动导航切换区块，不跳转页面。
- **结构特征**：多个纵向区块堆叠，导航锚点滚动定位。
- **动效特征**：平滑滚动、区块进场、滚动叙事。
- **适用场景**：官网、产品介绍、活动页、个人主页、SaaS 落地页。
- **技术实现**：锚点导航 + Lenis 平滑滚动 + GSAP ScrollTrigger。
- **代表案例**：Apple 产品页、各类 SaaS 官网、作品集。
- **关键词**：单页、single page、锚点、长滚动、落地页

### 1.2 多页式布局（Multi-page）
- **定义**：内容拆分为多个独立页面，通过导航跳转链接。
- **结构特征**：多个独立 HTML 页面，统一导航与页脚。
- **动效特征**：页面跳转过渡、面包屑导航。
- **适用场景**：企业官网、新闻门户、电商、后台系统。
- **技术实现**：传统多页 / SSR / Next.js 页面路由。
- **代表案例**：新浪、淘宝、企业官网、新闻网站。
- **关键词**：多页、multi-page、跳转、路由、网站

### 1.3 长滚动布局（Long Scroll）
- **定义**：单页内内容超长纵向滚动，用滚动驱动浏览节奏。
- **结构特征**：超长纵向内容，区块分层。
- **动效特征**：滚动叙事、视差、进场动画、进度条。
- **适用场景**：品牌故事、产品展示、数据报道、作品集。
- **技术实现**：ScrollTrigger + Lenis + 视差。
- **代表案例**：Apple 发布会页、纽约时报专题、获奖官网。
- **关键词**：长滚动、long scroll、纵向、叙事、沉浸

### 1.4 首屏聚焦布局（Hero-focused）
- **定义**：首屏（Hero）占据整屏视觉焦点，信息高度聚焦。
- **结构特征**：首屏大图/大字，其余内容次之。
- **动效特征**：首屏入场动画、背景动效。
- **适用场景**：官网首页、产品落地页、活动页。
- **技术实现**：`min-height: 100vh` + 首屏动画。
- **代表案例**：绝大多数官网首屏。
- **关键词**：首屏、hero、聚焦、100vh、焦点

### 1.5 分屏布局（Split Screen）
- **定义**：页面左右（或上下）对半分割，两侧承载不同内容。
- **结构特征**：左右对称分区、双内容区。
- **动效特征**：两侧错位入场、悬停分区扩展。
- **适用场景**：品牌双产品对比、登录注册页、创意官网。
- **技术实现**：CSS Grid/Flex 对半 + 响应式堆叠。
- **代表案例**：创意官网、产品对比页、双入口登录页。
- **关键词**：分屏、split screen、对半、双栏、对比

### 1.6 全屏背景布局（Fullscreen Background）
- **定义**：以全屏图片/视频作为背景，内容叠加其上。
- **结构特征**：全屏背景 + 前景内容层。
- **动效特征**：背景缩放（Ken Burns）、视频循环、视差。
- **适用场景**：首屏、品牌官网、活动页、旅游/摄影。
- **技术实现**：全屏 `<img>/<video>` + 覆盖层。
- **代表案例**：旅游官网、酒店官网、摄影作品集。
- **关键词**：全屏背景、fullscreen、视频背景、覆盖、氛围

### 1.7 杂志式布局（Magazine Layout）
- **定义**：模仿纸质杂志的多样图文混排，区块大小错落、视觉丰富。
- **结构特征**：图文混排、大小模块、头图+摘要。
- **动效特征**：模块错落入场、悬停预览。
- **适用场景**：门户、新闻、时尚、媒体内容站。
- **技术实现**：CSS Grid 混合网格 + 图文模块。
- **代表案例**：纽约时报、Vogue、时尚媒体首页。
- **关键词**：杂志、magazine、图文混排、门户、媒体

### 1.8 栅格布局（Grid Layout）
- **定义**：以规整的栅格（行列）组织内容，秩序感强。
- **结构特征**：规整行列、对齐清晰。
- **动效特征**：卡片入场、栅格重排。
- **适用场景**：作品集、图片库、商品列表、仪表盘。
- **技术实现**：CSS Grid / Bootstrap Grid。
- **代表案例**：Unsplash、Pinterest（部分）、作品集。
- **关键词**：栅格、grid、行列、规整、对齐

### 1.9 卡片式布局（Card-based Layout）
- **定义**：以独立卡片组织信息，边界清晰、易扫描。
- **结构特征**：圆角卡片、阴影、均匀分布。
- **动效特征**：卡片悬停、展开、翻转。
- **适用场景**：信息聚合、电商、新闻、设置页。
- **技术实现**：Flex/Grid + 卡片组件。
- **代表案例**：Pinterest、Airbnb、各类信息流。
- **关键词**：卡片、card、聚合、模块化、扫描

### 1.10 瀑布流布局（Masonry Layout）
- **定义**：多列等高不对齐的瀑布式排布，视觉错落紧凑。
- **结构特征**：多列错落、紧凑排布。
- **动效特征**：滚动加载、卡片错落入场。
- **适用场景**：图片社区、画廊、电商商品墙。
- **技术实现**：CSS columns / JS 瀑布流库（Masonry.js）。
- **代表案例**：Pinterest、花瓣、图片站。
- **关键词**：瀑布流、masonry、图片墙、错落、多列

### 1.11 便当盒布局（Bento Grid）
- **定义**：大小不一的圆角卡片模块化排布，像日式便当盒一样规整又活泼。
- **结构特征**：圆角卡片、大小混合、模块化。
- **动效特征**：卡片入场、悬停展开。
- **适用场景**：功能展示、作品集、数据概览、App 介绍页。
- **技术实现**：CSS Grid + 圆角卡片（可跨行列）。
- **代表案例**：Apple Keynote 页面、产品官网、个人主页。
- **关键词**：便当盒、Bento Grid、模块化、混合大小、圆角

### 1.12 视差分层布局（Parallax Layered）
- **定义**：前景、中景、背景以不同速度滚动，制造纵深层次。
- **结构特征**：多层内容，速度差。
- **动效特征**：滚动错位、景深、视差。
- **适用场景**：品牌官网、故事化页面、游戏官网。
- **技术实现**：GSAP 多层 transform + scroll。
- **代表案例**：Apple 产品页、游戏官网、获奖作品。
- **关键词**：视差、parallax、分层、景深、错位

## 二、阅读路径布局模式

> 依据用户视线扫描规律设计的布局，提升信息传达效率。

### 2.1 F 型布局（F-pattern）
- **定义**：用户视线呈"F"形扫描：先横向扫顶部，再向下扫左侧，横向扫描逐渐变短。
- **结构特征**：重要信息靠左、靠上排列，左侧为视觉主轴。
- **动效特征**：通常克制，以内容优先级为主。
- **适用场景**：文章、搜索结果、新闻列表、文档。
- **技术实现**：左侧对齐内容 + 层次化排版。
- **代表案例**：Google 搜索、新闻列表、技术文档。
- **关键词**：F型、F-pattern、视线、扫描、左对齐

### 2.2 Z 型布局（Z-pattern）
- **定义**：用户视线沿"Z"字形移动：左上→右上→左下→右下。
- **结构特征**：logo 左上、主内容中部、行动按钮右下。
- **动效特征**：关键 CTA 处动效引导注意力。
- **适用场景**：落地页、首屏、营销页（图文少时）。
- **技术实现**：对角线视觉引导 + CTA 布局。
- **代表案例**：简洁营销落地页、品牌首页。
- **关键词**：Z型、Z-pattern、视线、对角线、CTA

### 2.3 古腾堡图（Gutenberg Diagram）
- **定义**：描述用户视线在均匀页面上的移动规律：左上→右上→左下→右下，形成四个关注区。
- **结构特征**：左上（首要视觉区）、右下（终点视觉区）最重要。
- **动效特征**：用动效引导视线从左上到右下。
- **适用场景**：均衡信息页、海报、广告、品牌页。
- **技术实现**：视觉重心布置在左上与右下。
- **代表案例**：广告、海报、均衡布局页面。
- **关键词**：古腾堡、Gutenberg、视线路径、关注区、四象限

### 2.4 对称布局（Symmetrical Layout）
- **定义**：以中轴为基准左右（或上下）对称，传达稳定、正式、庄重。
- **结构特征**：左右镜像对称、居中中轴。
- **动效特征**：对称展开、居中聚焦。
- **适用场景**：高端品牌、婚纱摄影、奢侈、正式企业。
- **技术实现**：CSS 居中 + 镜像结构。
- **代表案例**：奢侈品牌官网、婚纱摄影、正式企业官网。
- **关键词**：对称、symmetrical、居中、庄重、正式

### 2.5 不对称布局（Asymmetrical / Broken Grid）
- **定义**：刻意打破对称与规整网格，用错位、重叠制造张力与个性。
- **结构特征**：不对称、错位、重叠、留白对比。
- **动效特征**：元素错位滑动、重叠交互。
- **适用场景**：创意作品集、时尚品牌、艺术网站。
- **技术实现**：负边距 + 重叠 + Grid 错位。
- **代表案例**：时尚品牌官网、创意工作室、设计师作品集。
- **关键词**：不对称、broken grid、错位、重叠、张力

## 三、导航布局模式

> 决定用户如何在应用/网站中移动与定位，是布局设计的核心。

### 3.1 顶部导航栏（Top Navigation）
- **定义**：固定在页面顶部的横向导航栏，含 logo、菜单、操作区。
- **结构特征**：横向顶部条、常驻显示。
- **动效特征**：滚动收缩、吸顶、菜单下拉。
- **适用场景**：官网、企业站、Web 应用。
- **技术实现**：CSS sticky/fixed + Flex 布局。
- **代表案例**：绝大多数网站顶部导航。
- **关键词**：顶部导航、top nav、吸顶、横向、常驻

### 3.2 底部标签栏（Bottom Tab Bar）
- **定义**：固定在屏幕底部的横向标签导航（移动端主流）。
- **结构特征**：底部 3-5 个标签、图标+文字。
- **动效特征**：标签切换、滚动隐藏、图标弹跳。
- **适用场景**：移动 App 主导航、小程序。
- **技术实现**：底部固定 + Tab 组件。
- **代表案例**：微信、抖音、淘宝、iOS 应用。
- **关键词**：底部标签栏、tab bar、移动端、主导航

### 3.3 抽屉式导航（Drawer / Hamburger）
- **定义**：默认隐藏、点击汉堡图标从侧边滑出的导航。
- **结构特征**：侧滑面板、汉堡菜单。
- **动效特征**：抽屉滑入滑出、遮罩渐显。
- **适用场景**：移动端、空间有限的界面、侧边菜单。
- **技术实现**：CSS transform 侧滑 + 遮罩。
- **代表案例**：移动端菜单、Material Design 抽屉。
- **关键词**：抽屉、drawer、汉堡、侧滑、菜单

### 3.4 侧边栏布局（Sidebar）
- **定义**：页面左侧（或右侧）常驻的竖向导航/信息栏。
- **结构特征**：左导航 + 右内容，竖向菜单。
- **动效特征**：侧栏折叠、展开、高亮跟随。
- **适用场景**：后台管理、文档站、桌面应用、博客。
- **技术实现**：Flex 布局（侧栏固定宽度 + 内容自适应）。
- **代表案例**：Notion、语雀、后台系统、文档站。
- **关键词**：侧边栏、sidebar、左导航、折叠、后台

### 3.5 顶部标签页（Top Tabs）
- **定义**：页面顶部横向排列的标签页，用于同层级内容切换。
- **结构特征**：顶部横向标签、内容区联动。
- **动效特征**：标签滑动指示器、内容淡入切换。
- **适用场景**：分类内容、频道、资料库、App 分类页。
- **技术实现**：Tab 组件 + 滑动指示器。
- **代表案例**：新闻频道、视频分类、设置页。
- **关键词**：标签页、tabs、分类、滑动指示器、切换

### 3.6 列表式导航（List Navigation）
- **定义**：以纵向列表展示导航项，常用于设置、菜单、目录。
- **结构特征**：纵向列表项、图标+文字+箭头。
- **动效特征**：列表项点击反馈、展开子项。
- **适用场景**：设置页、菜单、目录、个人中心。
- **技术实现**：List 组件 + 分组。
- **代表案例**：iOS 设置、各类菜单列表。
- **关键词**：列表、list、纵向、设置、菜单

### 3.7 九宫格 / 仪表盘导航（Dashboard Grid）
- **定义**：以图标网格（九宫格）形式展示功能入口。
- **结构特征**：网格图标入口、宫格排列。
- **动效特征**：图标悬停、入口弹跳、可拖拽排序。
- **适用场景**：App 首页、管理后台首页、门户首页。
- **技术实现**：CSS Grid + 图标组件。
- **代表案例**：支付宝首页、后台工作台、门户导航。
- **关键词**：九宫格、宫格、dashboard、入口、图标网格

### 3.8 命令面板（Command Palette）
- **定义**：通过快捷键唤出的全局搜索/命令输入面板，实现无鼠标快速操作。
- **结构特征**：居中弹层 + 搜索框 + 命令列表。
- **动效特征**：面板弹出、搜索结果实时过滤、高亮。
- **适用场景**：效率工具、编辑器、开发者工具。
- **技术实现**：全局快捷键 + 弹层 + 模糊搜索。
- **代表案例**：Raycast、VS Code、Notion、Slack。
- **关键词**：命令面板、command palette、快捷键、搜索、效率

### 3.9 面包屑导航（Breadcrumb）
- **定义**：显示当前页面在层级结构中的位置，支持逐级返回。
- **结构特征**：层级路径、分隔符（>/·）、逐级链接。
- **动效特征**：通常静态，悬停反馈。
- **适用场景**：电商、文档、后台、深度层级网站。
- **技术实现**：列表 + 分隔符样式。
- **代表案例**：淘宝、电商分类、文档站、后台系统。
- **关键词**：面包屑、breadcrumb、层级、路径、返回

## 四、首页与落地页布局

> 落地页/首页的高转化率布局套路。

### 4.1 居中 Hero 布局（Centered Hero）
- **定义**：首屏内容（标题、副标题、CTA）居中排列。
- **结构特征**：居中文案 + 居中按钮。
- **动效特征**：文案淡入上浮、按钮强调。
- **适用场景**：SaaS、App 下载、品牌首页。
- **技术实现**：Flex 居中 + 首屏动画。
- **代表案例**：各类 SaaS 官网、App 落地页。
- **关键词**：居中、centered hero、首屏、CTA、SaaS

### 4.2 左文右图 Hero 布局（Left Text / Right Image）
- **定义**：首屏左侧文字说明、右侧产品图/插画的经典分栏。
- **结构特征**：左右分栏，左文案右视觉。
- **动效特征**：图文错位入场、图片动效。
- **适用场景**：产品介绍、App 落地页、SaaS。
- **技术实现**：CSS Grid 两栏 + 响应式堆叠。
- **代表案例**：Slack、Dropbox、各类 SaaS 首页。
- **关键词**：左文右图、分栏、hero、产品图、落地页

### 4.3 三段式布局（Hero - Features - CTA）
- **定义**：经典落地页结构：首屏引入 → 功能/卖点 → 行动号召。
- **结构特征**：三个纵向区块递进。
- **动效特征**：区块进场、滚动引导。
- **适用场景**：SaaS、App、活动落地页。
- **技术实现**：纵向区块 + 滚动动画。
- **代表案例**：绝大多数落地页。
- **关键词**：三段式、features、CTA、落地页、递进

### 4.4 定价页布局（Pricing）
- **定义**：多档套餐卡片并排对比，突出推荐档。
- **结构特征**：多卡并排、推荐卡高亮、价格对比。
- **动效特征**：卡片悬停、推荐卡强调、切换计费周期。
- **适用场景**：SaaS、订阅服务、会员制产品。
- **技术实现**：卡片 Grid + 强调样式 + 切换器。
- **代表案例**：Notion、各类 SaaS 定价页。
- **关键词**：定价、pricing、套餐、对比、订阅

### 4.5 案例 / 作品集布局（Case Study / Portfolio）
- **定义**：以项目案例卡片展示成果，点击进入详情。
- **结构特征**：案例卡片网格/列表、缩略图+标题。
- **动效特征**：卡片入场、悬停预览、放大转场。
- **适用场景**：设计公司、工作室、个人作品集、B2B。
- **技术实现**：Grid/List + 悬停效果 + 详情页。
- **代表案例**：设计工作室官网、Awwwards 作品集。
- **关键词**：案例、作品集、portfolio、case study、展示

## 五、内容页布局

## 七、响应式与栅格系统

> 支撑布局在不同设备上自适应与一致呈现的底层系统。

### 7.1 12 栏栅格系统（12-column Grid）
- **定义**：将页面横向划分为 12 等份，元素按列数（1-12）占用宽度的标准栅格。
- **结构特征**：12 等分、列间距（gutter）、可组合。
- **动效特征**：栅格重排、响应式断点切换。
- **适用场景**：几乎所有网页设计。
- **技术实现**：CSS Grid / Bootstrap / Ant Design Grid。
- **代表案例**：Bootstrap、Ant Design、各类设计系统。
- **关键词**：12栏、栅格、column、gutter、设计系统

### 7.2 移动优先（Mobile-first）
- **定义**：先设计移动端，再向大屏渐进增强的设计策略。
- **结构特征**：从小屏到桌面逐级增强。
- **动效特征**：断点间平滑过渡。
- **适用场景**：移动端主导的产品、响应式网站。
- **技术实现**：CSS 从 `min-width` 媒体查询渐进。
- **代表案例**：移动优先的现代网站。
- **关键词**：移动优先、mobile-first、渐进增强、响应式

### 7.3 响应式断点（Breakpoints）
- **定义**：定义不同屏幕尺寸的临界点，布局在临界点切换。
- **结构特征**：多档断点（手机/平板/桌面）。
- **动效特征**：断点切换时布局重排。
- **适用场景**：所有响应式布局。
- **技术实现**：`@media` 媒体查询（576/768/992/1200px 等）。
- **代表案例**：Bootstrap 断点体系。
- **关键词**：断点、breakpoint、媒体查询、响应式、屏幕尺寸

### 7.4 自适应 vs 响应式（Adaptive vs Responsive）
- **定义**：自适应（Adaptive）= 针对特定设备预设多套固定布局；响应式（Responsive）= 一套布局流式连续调整。
- **结构特征**：自适应多套固定版式；响应式流式伸缩。
- **动效特征**：响应式连续过渡更平滑。
- **适用场景**：自适应适合复杂桌面应用；响应式适合内容网站。
- **技术实现**：自适应多断点固定设计；响应式流式 + 媒体查询。
- **代表案例**：自适应（部分后台）；响应式（主流网站）。
- **关键词**：自适应、响应式、adaptive、responsive、流式

### 7.5 弹性盒子布局（Flexbox）
- **定义**：一维布局模型，沿主轴/交叉轴弹性排列对齐元素。
- **结构特征**：单行/单列弹性排布、居中、等分。
- **动效特征**：flex 过渡、排列重排。
- **适用场景**：导航、卡片内排布、居中、工具条。
- **技术实现**：CSS `display: flex` + 对齐属性。
- **代表案例**：几乎所有现代布局。
- **关键词**：弹性盒子、flexbox、一维、对齐、居中

### 7.6 流式布局（Fluid Layout）
- **定义**：使用百分比/相对单位，宽度随视口流式伸缩。
- **结构特征**：宽度随容器百分比伸缩。
- **动效特征**：随视口连续变化。
- **适用场景**：响应式网站、内容流。
- **技术实现**：百分比 + `max-width` + `clamp()`。
- **代表案例**：现代响应式网站。
- **关键词**：流式、fluid、百分比、伸缩、clamp

### 7.7 固定宽度布局（Fixed-width Layout）
- **定义**：页面内容区固定像素宽度，不随视口变化。
- **结构特征**：固定宽度容器、居中。
- **动效特征**：无响应式变化。
- **适用场景**：老式网站、特定桌面工具、邮件模板。
- **技术实现**：固定 `width` + `margin: auto`。
- **代表案例**：老式网站、部分邮件模板。
- **关键词**：固定宽度、fixed-width、桌面、居中、老式
