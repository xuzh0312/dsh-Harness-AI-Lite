06 / RELIEF

新拟态

1.1 · 1.3

同背景、同控件，只替换双重阴影：外阴影让控件凸起，内阴影让控件凹陷。不要把阴影当成唯一状态提示。

光影切片 / 左上光源

仅展示外观，不执行操作。保留深色文字、边框和独立焦点环；仅凭柔和阴影的对比度不足。

09 / COLOR

极光渐变 vs 网格渐变

2.1 · 2.2

同一张标签：极光常用斜向扩散的柔光带，网格常让多个色点平滑交织。两者能重叠，这里对比的是视觉习惯，不是严格的数学分类。

背景切片 / 全部静态

极光用 CSS 叠加并模糊两条光带；网格用 SVG 将上下两排色点横向插值，再纵向混合，是简化的网格近似。
