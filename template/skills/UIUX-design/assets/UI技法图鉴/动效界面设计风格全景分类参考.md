## 一、材质拟态类

> 核心思想：用光影、模糊、阴影模拟现实世界材质的质感，让界面"有物理触感"。

### 1.1 扁平化设计（Flat Design）
- **定义**：去除阴影、渐变、纹理的二维极简风格，是拟物化之后的"减法"设计。
- **视觉特征**：纯色块、无阴影、清晰排版、符号化图标。
- **动效特征**：简单过渡、位移动画，动效克制。
- **适用场景**：功能性后台、企业官网、工具类应用、数据大屏。
- **技术实现**：纯 CSS，无特殊依赖。
- **代表案例**：早期 iOS 7、Windows 8/10、Google Material Design（早期）。
- **关键词**：扁平、极简、minimal、flat、2D

### 1.2 拟物化设计（Skeuomorphism）
- **定义**：界面元素模仿真实物体的材质、纹理与光影（如皮革、金属、纸张）。
- **视觉特征**：真实质感、丰富阴影、立体层次。
- **动效特征**：按压回弹、翻页、真实物理反馈。
- **适用场景**：复古怀旧产品、游戏 UI、电子书阅读器、拟物细节点缀。
- **技术实现**：位图素材 + 多重阴影/渐变。
- **代表案例**：早期 iOS 1-6、经典计算器、iBooks 书架。
- **关键词**：拟物、真实质感、skeuomorphic、realistic

### 1.3 新拟态（Neumorphism / Soft UI）
- **定义**：用同色系"亮边 + 暗边"双重柔和阴影，模拟元素从背景"凸起/凹陷"的实体感。
- **视觉特征**：低对比、柔和、与背景同色系，边缘有柔和光影。
- **动效特征**：按压时阴影反转，凹陷下沉。
- **适用场景**：开关、滑块、按钮、音量控件等小面积组件（不宜大面积使用，易导致可读性差）。
- **技术实现**：双重 `box-shadow`（左上亮 + 右下暗）。
- **代表案例**：Dribbble 概念稿、部分智能家居 App 控件。
- **关键词**：新拟态、软 UI、neumorphism、soft UI、双重阴影

### 1.4 玻璃拟态（Glassmorphism）
- **定义**：毛玻璃效果，通过背景模糊 + 半透明叠加，制造"悬浮玻璃层"的层次感。
- **视觉特征**：背景模糊、半透明白描边、轻微高光、通透。
- **动效特征**：悬浮、缩放、背景穿透过渡。
- **适用场景**：仪表盘、浮动导航、弹窗、卡片、侧边栏、登录页。
- **技术实现**：CSS `backdrop-filter: blur()` + 半透明边框 + 多层 z-index。
- **代表案例**：Apple macOS 通知中心、iOS 控制中心、macOS Big Sur。
- **关键词**：玻璃拟态、毛玻璃、glassmorphism、frosted glass、backdrop-filter

### 1.5 液态玻璃（Liquid Glass）
- **定义**：苹果 WWDC25（2025 年 6 月）发布的下一代设计语言，一种能实时折射、反射、聚光的半透明自适应材质，控件会随交互"流动变形"。
- **视觉特征**：实时折射/反射高光、随内容与明暗自适应、与屏幕圆角呼应、全透明模式。
- **动效特征**：控件随触摸/滚动动态变形（shapeshift）、菜单弹出、播放控制与界面互动、滚动时标签栏缩小/展开。
- **适用场景**：App 导航栏、悬浮工具栏、菜单弹出、播放控制、系统级界面。
- **技术实现**：iOS 26 SDK / SwiftUI 系统组件；第三方需仿写（`backdrop-filter` + 动态高光 + 弹簧动效 + 实时渲染）。
- **代表案例**：iOS 26、iPadOS 26、macOS Tahoe 26、watchOS 26 系统界面。
- **关键词**：液态玻璃、Liquid Glass、苹果、实时渲染、流体材质、透明

### 1.6 粘土拟态（Claymorphism）
- **定义**：圆润、胖乎乎、柔软的 3D 黏土质感，边缘有柔和内阴影和外高光。
- **视觉特征**：大圆角、柔和内阴影、奶油色系、可爱童趣。
- **动效特征**：Q 弹缩放、轻弹、挤压。
- **适用场景**：引导页插画、教育/儿童/娱乐产品、吉祥物、图标、空状态。
- **技术实现**：CSS 内阴影 + 边缘高光，或 Figma / Spline 建模。
- **代表案例**：3D 插画风官网、部分 SaaS 引导页。
- **关键词**：粘土拟态、claymorphism、圆润、可爱、3D 插画

### 1.7 极光拟态（Auromorphism）
- **定义**：融合极光渐变与拟态质感，用柔和的彩色光晕营造梦幻氛围。
- **视觉特征**：多色柔光、朦胧光晕、柔和边界。
- **动效特征**：光晕缓慢流动、呼吸。
- **适用场景**：品牌氛围、科技感登录页、创意产品首屏。
- **技术实现**：多径向渐变 + `filter: blur()` + 位移动画。
- **代表案例**：AI 产品官网、创意工作室首页。
- **关键词**：极光、auromorphism、光晕、梦幻、渐变

### 1.8 铬金属拟态（Chrome Morphism）
- **定义**：模拟液态金属铬的镜面高光质感，充满未来感。
- **视觉特征**：镜面反射、银/彩色金属渐变、强高光。
- **动效特征**：高光扫过、光泽流动。
- **适用场景**：科技品牌、游戏 UI、潮玩、Web3 / 加密货币界面。
- **技术实现**：复杂多层渐变 + 高光蒙版 + 动画。
- **代表案例**：Web3 网站、电竞产品、潮流品牌官网。
- **关键词**：铬、金属、chrome、metallic、未来感

### 1.9 材质模拟类（Material Simulation）
- **定义**：模拟木材、纸张、布料、混凝土、塑料等多样现实材质的质感。
- **视觉特征**：真实纹理、多样材质对比。
- **动效特征**：材质特有反馈（翻页、弹性、摩擦）。
- **适用场景**：品牌官网、电商、阅读产品、高端设计作品集。
- **技术实现**：位图纹理 + 光影 + 混合模式。
- **代表案例**：纸张质感阅读 App、木纹电商、混凝土风官网。
- **关键词**：材质、纹理、texture、模拟、质感

## 二、光影色彩类

> 核心思想：用光、色、渐变、噪点营造氛围与情绪。

### 2.1 极光渐变（Aurora Gradient）
- **定义**：多色柔光缓慢流动、像极光一样漫射的背景。
- **视觉特征**：多色柔光、朦胧、动态流动。
- **动效特征**：渐变缓慢位移、旋转、呼吸。
- **适用场景**：首屏 Hero、登录页、品牌氛围背景、SaaS 官网。
- **技术实现**：CSS 多径向渐变 + `blur()` + 位移动画，或 WebGL。
- **代表案例**：Stripe、Vercel 早期官网、各类 AI 产品首页。
- **关键词**：极光、渐变、aurora、gradient、流动

### 2.2 网格渐变（Mesh Gradient）
- **定义**：多点颜色平滑交织形成的"网格状"渐变，颜色过渡细腻丰富。
- **视觉特征**：多色交织、细腻过渡、抽象。
- **动效特征**：颜色点缓慢漂移、交织流动。
- **适用场景**：品牌视觉、海报、App 背景、插画。
- **技术实现**：Figma mesh gradient / SVG + 滤镜 / WebGL shader。
- **代表案例**：Procreate 素材、创意品牌官网。
- **关键词**：网格渐变、mesh gradient、抽象、交织

### 2.3 霓虹发光（Neon Glow）
- **定义**：霓虹灯管般的发光效果，高饱和色彩 + 强光晕。
- **视觉特征**：高饱和、发光描边、暗背景、赛博感。
- **动效特征**：闪烁、呼吸、电流流动。
- **适用场景**：游戏、潮流品牌、夜店/音乐节、科技活动页。
- **技术实现**：`text-shadow` / `box-shadow` 多层光晕 + 动画。
- **代表案例**：赛博朋克风格官网、电竞、音乐节活动页。
- **关键词**：霓虹、发光、neon、glow、赛博朋克

### 2.4 金属渐变（Metallic Gradient）
- **定义**：模拟金银铜等金属光泽的渐变，营造奢华/科技感。
- **视觉特征**：金属高光、金银色系、锐利明暗对比。
- **动效特征**：高光扫过、光泽流动。
- **适用场景**：金融、奢侈品、奖牌/等级徽章、游戏成就。
- **技术实现**：线性/角度渐变 + 高光蒙版。
- **代表案例**：金融 App 等级徽章、奢侈品牌官网、游戏成就系统。
- **关键词**：金属、金色、metallic、luxury、光泽

### 2.5 噪点纹理（Noise / Grain Texture）
- **定义**：在界面上叠加细微颗粒噪点，增加质感与"呼吸感"，消除大色块生硬感。
- **视觉特征**：细腻颗粒、柔和、胶片感。
- **动效特征**：噪点轻微闪烁、颗粒流动（动画噪点）。
- **适用场景**：渐变背景、插画、品牌官网、暗色界面。
- **技术实现**：SVG feTurbulence / Canvas 噪点 / 位图叠加 + `mix-blend-mode`。
- **代表案例**：Figma、Linear、各类高端官网。
- **关键词**：噪点、颗粒、noise、grain、胶片感

### 2.6 暗色模式（Dark Mode）
- **定义**：深色背景界面，减少眩光、节省 OLED 电量，现已成为产品默认选项。
- **视觉特征**：深灰/纯黑背景、高对比、自适应对比度。
- **动效特征**：明暗切换平滑过渡、色彩自适应。
- **适用场景**：几乎所有现代应用（开发者工具、内容消费、社交）。
- **技术实现**：CSS `prefers-color-scheme` / 主题变量 / 系统检测。
- **代表案例**：Notion、Linear、Raycast、macOS 深色模式。
- **关键词**：暗色模式、深色、dark mode、主题、对比度

### 2.7 高对比粗野主义（Brutalism）
- **定义**：刻意粗糙、原始、高对比的设计，大字号、单色、粗边框，强调功能与反叛。
- **视觉特征**：大字号、黑白/高饱和、硬边框、无修饰。
- **动效特征**：生硬位移、闪烁、抖动（刻意"不精致"）。
- **适用场景**：创意工作室、个人品牌、潮流文化、独立出版物。
- **技术实现**：纯 CSS，重在排版与配色。
- **代表案例**：部分独立设计师官网、潮流品牌、文化媒体。
- **关键词**：粗野主义、brutalism、反叛、高对比、原始

## 三、风格美学类

> 核心思想：具有强烈文化/时代印记的视觉美学，常与动效结合。

### 3.1 故障艺术（Glitch Effect）
- **定义**：模拟数字信号故障的错位、撕裂、RGB 分离效果。
- **视觉特征**：RGB 色彩分离、错位、撕裂、雪花噪点。
- **动效特征**：闪烁、抖动、错位跳动。
- **适用场景**：音乐人官网、潮流品牌、游戏、实验性作品。
- **技术实现**：CSS clip-path 错位 + RGB 通道分离动画 / Canvas。
- **代表案例**：音乐节官网、实验性设计作品。
- **关键词**：故障、glitch、RGB 分离、错位、数字故障

### 3.2 像素风（Pixel Art）
- **定义**：模仿 8bit / 16bit 像素游戏的复古风格。
- **视觉特征**：像素块、有限色板、复古游戏感。
- **动效特征**：逐帧像素动画、复古 UI 交互。
- **适用场景**：独立游戏、复古主题、开发者个人页、趣味营销。
- **技术实现**：CSS `image-rendering: pixelated` + 逐帧动画。
- **代表案例**：复古游戏、像素风官网。
- **关键词**：像素、pixel art、8bit、复古、游戏

### 3.3 Y2K / 蒸汽波（Y2K / Vaporwave）
- **定义**：千禧年科技乐观主义 + 复古电子美学，融合金属、塑料、渐变与复古互联网元素。
- **视觉特征**：粉紫蓝渐变、金属质感、塑料感、复古网页元素。
- **动效特征**：闪烁、旋转、梦幻漂移。
- **适用场景**：潮流品牌、音乐、复古主题、Z 世代文化产品。
- **技术实现**：CSS 渐变 + 位图素材 + 复古动效。
- **代表案例**：潮流品牌、蒸汽波音乐视觉。
- **关键词**：Y2K、蒸汽波、vaporwave、复古未来、千禧年

### 3.4 孟菲斯 / 波普（Memphis / Pop）
- **定义**：大胆几何图形、高饱和撞色、波普艺术感的活泼风格。
- **视觉特征**：几何图形、撞色、波点、条纹、活泼。
- **动效特征**：弹跳、旋转、错落出现。
- **适用场景**：创意品牌、教育、活动、年轻化产品。
- **技术实现**：CSS 几何图形 + 动画。
- **代表案例**：创意活动海报、年轻品牌官网。
- **关键词**：孟菲斯、波普、memphis、pop、撞色

### 3.5 极简主义（Minimalism）
- **定义**：以留白、克制、秩序为核心的极致简洁风格。
- **视觉特征**：大量留白、单一强调色、清晰层级。
- **动效特征**：克制、缓慢、精准的过渡。
- **适用场景**：高端品牌、奢侈品、SaaS、内容平台。
- **技术实现**：纯 CSS，重在排版与留白。
- **代表案例**：Apple、Muji、Linear、各类高端品牌。
- **关键词**：极简、minimalism、留白、克制、高端

### 3.6 玻璃朋克 / 未来透明（Glasspunk / Futuristic Transparency）
- **定义**：大面积透明、全息、虹彩反射的未来科技视觉。
- **视觉特征**：全息虹彩、透明层叠、未来感光效。
- **动效特征**：虹彩流动、光效扫过。
- **适用场景**：AR/VR、AI 产品、科技发布会、概念界面。
- **技术实现**：渐变叠加 + 混合模式 + 动画。
- **代表案例**：Vision Pro 概念界面、AI 产品宣传。
- **关键词**：未来、透明、全息、holographic、futuristic

## 四、微交互与动效类

> 核心思想：小而精准的动效反馈，让界面"活"起来、有温度。

### 4.1 微交互（Microinteractions）
- **定义**：针对单个交互动作（点击、悬停、滑动）的即时、精准反馈。
- **视觉特征**：元素级细节变化。
- **动效特征**：按压、弹跳、图标轻旋、点赞爆裂、开关切换。
- **适用场景**：所有交互组件（按钮、表单、Tab、收藏、点赞）。
- **技术实现**：CSS transition / Framer Motion / Lottie。
- **代表案例**：Twitter 点赞、iOS 开关、Airbnb 收藏。
- **关键词**：微交互、microinteraction、反馈、细节、弹跳

### 4.2 骨架屏（Skeleton Screen）
- **定义**：内容加载前用灰色占位块模拟页面结构，替代传统转圈加载。
- **视觉特征**：灰色渐变占位块，形状与内容一致。
- **动效特征**：微光扫过（shimmer）动画。
- **适用场景**：列表、卡片、详情页加载。
- **技术实现**：CSS 渐变 + 微光动画。
- **代表案例**：Facebook、LinkedIn、知乎等绝大多数现代应用。
- **关键词**：骨架屏、skeleton、加载、占位、微光

### 4.3 创意加载动画（Creative Loading）
- **定义**：品牌化、趣味化的加载动画，缓解等待焦虑。
- **视觉特征**：品牌元素、趣味图形、进度反馈。
- **动效特征**：循环动画、进度推进、转场收尾。
- **适用场景**：启动页、游戏加载、品牌官网。
- **技术实现**：Lottie / SVG / Canvas / CSS。
- **代表案例**：Google 系列、游戏加载画面、品牌启动页。
- **关键词**：加载、loading、启动、进度、品牌

### 4.4 页面转场（Page Transition）
- **定义**：页面/视图切换时的过渡动画，保持空间连续感。
- **视觉特征**：滑动、淡入淡出、缩放、覆盖。
- **动效特征**：平滑过渡、方向感、层次感。
- **适用场景**：App 导航、SPA 页面切换、移动端路由。
- **技术实现**：CSS transition / Vue Transition / Framer Motion / React Navigation。
- **代表案例**：iOS 导航、各类移动应用。
- **关键词**：转场、过渡、transition、页面切换、导航

### 4.5 共享元素转场（Shared Element Transition）
- **定义**：同一元素在两个界面间连续运动，建立空间关联（如列表图片放大进入详情）。
- **视觉特征**：元素跨界面连续变形。
- **动效特征**：元素飞入/放大/缩小，无缝衔接。
- **适用场景**：列表→详情、图片浏览、搜索到结果。
- **技术实现**：Flutter Hero / Android Shared Element / React Native 相关库。
- **代表案例**：Google Play、淘宝商品详情、Pinterest。
- **关键词**：共享元素、shared element、hero、转场、关联

### 4.6 弹簧物理动效（Spring Animation）
- **定义**：模拟真实弹簧物理的运动曲线（有回弹、有阻尼），让动效更自然。
- **视觉特征**：运动轨迹自然、有回弹。
- **动效特征**：过冲回弹、阻尼衰减、跟随拖拽。
- **适用场景**：可拖拽元素、弹窗、开关、卡片位移。
- **技术实现**：Framer Motion `spring` / React Spring / SwiftUI spring。
- **代表案例**：iOS 弹窗、Framer 拖拽、Material Design。
- **关键词**：弹簧、spring、物理、回弹、阻尼

### 4.7 流体粘性变形（Gooey Effect）
- **定义**：元素靠近时像液体一样"粘连→融合→分离"的 Q 弹变形效果。
- **视觉特征**：液态融合、Q 弹、丝滑。
- **动效特征**：融合、分离、粘性拉伸。
- **适用场景**：播放器按钮展开、菜单变体、logo 变形、加载。
- **技术实现**：SVG `filter: gooey`（高斯模糊 + 对比度拉伸）。
- **代表案例**：各类 Dribbble 概念、播放器 UI。
- **关键词**：流体、粘性、gooey、融合、变形

### 4.8 粒子动效（Particle Effect）
- **定义**：大量微小粒子组成的动态视觉效果。
- **视觉特征**：粒子群、光点、星尘、火花。
- **动效特征**：粒子漂浮、聚散、拖尾、爆炸。
- **适用场景**：品牌背景、活动页、游戏、数据可视化。
- **技术实现**：Canvas / WebGL / Particle.js / Three.js。
- **代表案例**：粒子背景官网、品牌活动页、游戏特效。
- **关键词**：粒子、particle、星尘、Canvas、WebGL

### 4.9 Lottie 矢量动画（Lottie Animation）
- **定义**：用 JSON 描述、可跨平台渲染的矢量动画（由 After Effects 通过 Bodymovin 导出）。
- **视觉特征**：矢量、可缩放、无损。
- **动效特征**：复杂补间动画、路径动画、可控进度。
- **适用场景**：品牌动效、图标动画、空状态、加载、引导。
- **技术实现**：Lottie（Web/iOS/Android/React Native）库渲染 JSON。
- **代表案例**：大量 App 的引导页与图标动画。
- **关键词**：Lottie、矢量动画、JSON、AE、跨平台

### 4.10 波纹动效（Ripple Effect）
- **定义**：点击时从触点扩散的波纹反馈（Material Design 标志性动效）。
- **视觉特征**：圆形波纹扩散。
- **动效特征**：从触点扩散、渐隐。
- **适用场景**：按钮、列表项、卡片点击反馈。
- **技术实现**：CSS / JS 定位圆形 + 缩放渐隐。
- **代表案例**：Material Design 全系组件。
- **关键词**：波纹、ripple、点击反馈、扩散、Material

## 五、滚动动效类

> 核心思想：以"滚动"为时间轴驱动动画，是网页叙事与沉浸体验的核心手段。

### 5.1 视差滚动（Parallax Scrolling）
- **定义**：前后景以不同速度移动，制造纵深感和立体感。
- **视觉特征**：多层元素速度差。
- **动效特征**：滚动时层级错位移动。
- **适用场景**：首屏、故事化长页、品牌官网。
- **技术实现**：GSAP / CSS transform + scroll / Lenis。
- **代表案例**：Apple 产品页、各类获奖官网。
- **关键词**：视差、parallax、景深、错位、滚动

### 5.2 滚动叙事（Scrollytelling）
- **定义**：用滚动驱动故事情节推进，边滚边讲，实现"沉浸式叙事"。
- **视觉特征**：内容随滚动逐步展开、场景切换。
- **动效特征**：章节推进、元素锁屏播放、逐帧动画。
- **适用场景**：品牌故事、产品介绍、数据报道、新闻专题。
- **技术实现**：GSAP ScrollTrigger / Framer Motion useScroll / ScrollMagic。
- **代表案例**：纽约时报专题、Apple 发布会页、ESPN 数据报道。
- **关键词**：滚动叙事、scrollytelling、故事、沉浸、ScrollTrigger

### 5.3 滚动进场动画（Scroll Reveal）
- **定义**：元素滚入视口时错落淡入、上浮、展开。
- **视觉特征**：元素错落出现。
- **动效特征**：淡入、上浮、缩放、错位延迟。
- **适用场景**：列表、卡片、章节标题、作品集。
- **技术实现**：IntersectionObserver / AOS / Framer Motion whileInView。
- **代表案例**：各类作品集、官网列表。
- **关键词**：进场、reveal、视口、淡入、AOS

### 5.4 平滑滚动（Smooth Scrolling）
- **定义**：滚动惯性平滑、无顿挫的滚动手感（如 Lenis 的 lerp 平滑）。
- **视觉特征**：滚动流畅如丝。
- **动效特征**：惯性滑动、缓动跟随。
- **适用场景**：高端官网、作品集、长页面。
- **技术实现**：Lenis / GSAP ScrollSmoother / Locomotive Scroll。
- **代表案例**：Awwwards 获奖网站普遍采用。
- **关键词**：平滑滚动、smooth scroll、Lenis、惯性、丝滑

### 5.5 滚动吸附（Scroll Snap）
- **定义**：滚动结束后自动吸附到指定位置，实现分屏/翻页式浏览。
- **视觉特征**：全屏分节、逐屏浏览。
- **动效特征**：吸附停顿、分屏切换。
- **适用场景**：全屏产品展示、画廊、移动端分屏。
- **技术实现**：CSS `scroll-snap-type` + `scroll-snap-align`。
- **代表案例**：Apple 产品分屏、全屏画廊网站。
- **关键词**：吸附、scroll snap、分屏、翻页、全屏

### 5.6 水平滚动（Horizontal Scroll）
- **定义**：横向滚动的布局，常用于画廊、时间轴、产品横向展示。
- **视觉特征**：横向排布、横向位移。
- **动效特征**：横向平移、与纵向滚动联动。
- **适用场景**：产品系列、画廊、时间轴、品牌案例。
- **技术实现**：GSAP 横向位移 + 纵向滚动联动。
- **代表案例**：品牌案例展示、作品集横向画廊。
- **关键词**：水平滚动、horizontal、横向、画廊、时间轴

### 5.7 无限滚动（Infinite Scroll）
- **定义**：滚动到底部自动加载更多内容，无缝衔接。
- **视觉特征**：内容持续追加。
- **动效特征**：加载提示、无缝衔接。
- **适用场景**：信息流、商品列表、社交 Feed。
- **技术实现**：IntersectionObserver + 分页接口。
- **代表案例**：Instagram、Twitter、淘宝、抖音。
- **关键词**：无限滚动、infinite scroll、加载更多、信息流

### 5.8 滚动进度条（Scroll Progress）
- **定义**：页面顶部/侧边的阅读进度指示器。
- **视觉特征**：进度条/圆形进度。
- **动效特征**：随滚动实时填充。
- **适用场景**：长文阅读、教程、博客。
- **技术实现**：scroll 监听 + 进度计算。
- **代表案例**：Medium、技术博客、长文阅读页。
- **关键词**：进度条、progress、阅读进度、滚动

## 六、3D 与空间类

> 核心思想：引入第三维度，让界面有空间纵深与沉浸感。

### 6.1 实时 3D 渲染（WebGL / Three.js）
- **定义**：浏览器/应用内实时渲染 3D 场景与对象。
- **视觉特征**：真实光影、3D 模型、可交互。
- **动效特征**：实时旋转、缩放、物理、着色器动画。
- **适用场景**：产品展示、游戏、品牌官网、可视化。
- **技术实现**：Three.js / React Three Fiber / Babylon.js / WebGL。
- **代表案例**：品牌 3D 官网、WebGL 获奖作品。
- **关键词**：3D、WebGL、Three.js、实时渲染、模型

### 6.2 3D 产品 360° 展示（360° Product View）
- **定义**：产品模型可拖拽旋转、缩放、拆解的 360 度展示。
- **视觉特征**：产品立体可旋转。
- **动效特征**：拖拽旋转、缩放、拆解动画。
- **适用场景**：电商、硬件官网、汽车、数码产品。
- **技术实现**：Three.js / Spline / 序列帧。
- **代表案例**：Apple 产品页、汽车官网、电商 3D 展示。
- **关键词**：360、产品展示、旋转、拆解、电商

### 6.3 伪 3D 倾斜（Tilt / 3D Hover）
- **定义**：元素随鼠标/陀螺仪产生透视倾斜，模拟 3D 深度（无需真实 3D 模型）。
- **视觉特征**：卡片透视倾斜、跟随鼠标。
- **动效特征**：透视旋转、跟随、回正。
- **适用场景**：卡片、支付卡、海报、作品集。
- **技术实现**：CSS transform 透视 + JS 鼠标跟随，或 Tilt.js。
- **代表案例**：支付卡倾斜、作品集卡片。
- **关键词**：倾斜、tilt、透视、跟随、3D hover

### 6.4 空间界面（Spatial UI）
- **定义**：将界面元素置于立体空间，玻璃材质悬浮分层（如 Vision Pro 的空间交互）。
- **视觉特征**：悬浮玻璃层、空间纵深、光影通透。
- **动效特征**：元素悬浮、空间位移、视差深度。
- **适用场景**：XR 设备、概念界面、未来感产品。
- **技术实现**：SwiftUI（visionOS）/ 3D 引擎 / 多层视差。
- **代表案例**：Apple Vision Pro、visionOS。
- **关键词**：空间界面、spatial、visionOS、悬浮、XR

### 6.5 AR / VR 界面（AR / VR Interface）
- **定义**：增强现实/虚拟现实的交互界面，界面与现实或虚拟世界融合。
- **视觉特征**：虚实融合、空间锚定。
- **动效特征**：空间定位、手势交互、环境响应。
- **适用场景**：AR 试戴/试装、VR 应用、游戏、教育。
- **技术实现**：ARKit / ARCore / WebXR / Unity。
- **代表案例**：宜家 AR 摆放、AR 试妆、VR 应用。
- **关键词**：AR、VR、增强现实、虚拟现实、WebXR

### 6.6 景深分层（Depth Layering）
- **定义**：通过阴影 + 模糊 + 层级堆叠，模拟"卡片浮在内容之上"的空间感。
- **视觉特征**：层级分明、悬浮感。
- **动效特征**：层叠展开、层次滑动。
- **适用场景**：弹窗、菜单、悬浮卡片、移动端导航。
- **技术实现**：z-index + 阴影 + 背景模糊。
- **代表案例**：iOS 弹窗、悬浮卡片设计。
- **关键词**：景深、分层、depth、悬浮、层级

## 七、排版动效类

> 核心思想：文字本身成为动态视觉元素，替代传统静态排版。

### 7.1 动态排版（Kinetic Typography）
- **定义**：文字运动、变形、变色，文字本身成为视觉主角。
- **视觉特征**：超大粗字、动态变化。
- **动效特征**：字重/字距/颜色随滚动变化、逐字动画。
- **适用场景**：官网首屏、活动页、品牌宣言、视频片头。
- **技术实现**：可变字体 + 滚动监听 / GSAP 逐字动画。
- **代表案例**：Apple 产品页、创意官网大标题。
- **关键词**：动态排版、kinetic typography、文字动效、逐字

### 7.2 文字揭示动画（Text Reveal）
- **定义**：文字以遮罩、裁剪、逐字等方式揭示出现。
- **视觉特征**：文字从遮罩后显现。
- **动效特征**：逐字/逐行淡入、上滑、遮罩裁剪。
- **适用场景**：标题、开场、章节标题。
- **技术实现**：CSS clip-path / overflow 遮罩 / GSAP SplitText。
- **代表案例**：获奖官网标题、品牌开场。
- **关键词**：文字揭示、text reveal、遮罩、逐字、SplitText

### 7.3 可变字体（Variable Font）
- **定义**：单一字体文件支持字重、字宽、斜体等连续变化的动态字体。
- **视觉特征**：字重/字宽平滑变化。
- **动效特征**：字重随滚动/交互连续变化。
- **适用场景**：动态标题、响应式排版、品牌。
- **技术实现**：CSS `font-variation-settings` + 动画。
- **代表案例**：各类创意官网动态标题。
- **关键词**：可变字体、variable font、字重、字宽

### 7.4 打字机效果（Typewriter）
- **定义**：文字逐字打出，模拟打字机输入，常配光标闪烁。
- **视觉特征**：逐字显现、闪烁光标。
- **动效特征**：逐字输出、光标闪烁、可循环。
- **适用场景**：终端风格、开场、个人页、命令行动效。
- **技术实现**：JS 逐字输出 / CSS steps()。
- **代表案例**：开发者个人页、终端风格网站。
- **关键词**：打字机、typewriter、逐字、终端、光标

### 7.5 超大标题排版（Big / Bold Typography）
- **定义**：超大粗体标题作为页面的主要视觉元素，替代传统 Hero 图。
- **视觉特征**：超大字号、粗体、占据主导。
- **动效特征**：入场、滚动缩放、错落出现。
- **适用场景**：官网首屏、活动页、品牌宣言。
- **技术实现**：CSS clamp() 响应式字号 + 动画。
- **代表案例**：创意官网、活动落地页。
- **关键词**：大字、bold、排版、Hero、标题

## 八、布局结构类

> 核心思想：布局本身成为视觉风格与体验的一部分。

### 8.1 便当盒布局（Bento Grid）
- **定义**：大小不一的圆角卡片模块化排布，像日式便当盒一样规整又活泼。
- **视觉特征**：圆角卡片、模块化、信息密度高。
- **动效特征**：卡片入场、悬停展开。
- **适用场景**：功能展示、作品集、数据概览、App 介绍页。
- **技术实现**：CSS Grid + 圆角卡片。
- **代表案例**：Apple 发布会 Keynote 页、各类产品官网。
- **关键词**：便当盒、Bento Grid、模块化、卡片、Grid

### 8.2 卡片式布局（Card UI）
- **定义**：以独立卡片组织信息，边界清晰、易扫描。
- **视觉特征**：圆角卡片、阴影、分隔清晰。
- **动效特征**：卡片悬停、展开、翻转。
- **适用场景**：信息聚合、电商、新闻、设置页。
- **技术实现**：CSS + 卡片组件。
- **代表案例**：Pinterest、Airbnb、各类信息流。
- **关键词**：卡片、card UI、信息聚合、圆角

### 8.3 无边距沉浸式（Edge-to-Edge / Borderless）
- **定义**：内容延伸到屏幕边缘，去除边框，营造沉浸感。
- **视觉特征**：全屏内容、无边界、视觉延展。
- **动效特征**：全屏过渡、沉浸滚动。
- **适用场景**：媒体、游戏、内容消费、移动端。
- **技术实现**：CSS 去除内边距 + 全屏布局。
- **代表案例**：iOS 26、沉浸式媒体应用。
- **关键词**：无边距、沉浸、edge-to-edge、全屏、延展

### 8.4 打破网格（Broken Grid / Asymmetry）
- **定义**：刻意打破规整网格，用不对称、错位、重叠制造张力与个性。
- **视觉特征**：不对称、错位、重叠、动态。
- **动效特征**：元素错位滑动、重叠交互。
- **适用场景**：创意作品集、时尚品牌、艺术网站。
- **技术实现**：CSS Grid/Flex 错位 + 负边距 + 重叠。
- **代表案例**：时尚品牌官网、创意工作室。
- **关键词**：打破网格、不对称、broken grid、错位、重叠

### 8.5 瀑布流布局（Masonry Layout）
- **定义**：多列等高不对齐的瀑布式排布，视觉错落。
- **视觉特征**：多列错落、紧凑。
- **动效特征**：滚动加载、卡片错落入场。
- **适用场景**：图片社区、画廊、电商商品墙。
- **技术实现**：CSS columns / JS 瀑布流库。
- **代表案例**：Pinterest、花瓣、图片站。
- **关键词**：瀑布流、masonry、图片墙、错落、多列

## 九、光标与手势交互类

> 核心思想：指针、手势、语音等"输入"本身成为设计的一部分。

### 9.1 自定义光标（Cursor Interaction）
- **定义**：鼠标指针变成磁吸圆点、拖尾光晕、放大镜等，跟随品牌元素变化。
- **视觉特征**：自定义指针形状、拖尾、光晕。
- **动效特征**：平滑跟随（lerp）、磁吸、形态切换。
- **适用场景**：个人作品集、创意工作室、电商详情页。
- **技术实现**：JS mousemove + lerp 插值。
- **代表案例**：Awwwards 创意网站普遍采用。
- **关键词**：光标、cursor、跟随、磁吸、拖尾

### 9.2 磁吸效果（Magnetic Effect）
- **定义**：元素被鼠标/手指靠近时产生吸附、拉伸的物理反应。
- **视觉特征**：元素向指针偏移。
- **动效特征**：吸附、拉伸、回弹。
- **适用场景**：按钮、图标、卡片、导航。
- **技术实现**：JS 距离计算 + transform 偏移。
- **代表案例**：创意官网按钮、图标磁吸。
- **关键词**：磁吸、magnetic、吸附、拉伸、物理

### 9.3 悬停动效（Hover Effect）
- **定义**：鼠标悬停时元素的视觉与动效反馈。
- **视觉特征**：颜色/阴影/缩放变化、图文揭示。
- **动效特征**：缩放、变色、展开、图片预览。
- **适用场景**：卡片、按钮、图片、导航、商品。
- **技术实现**：CSS :hover + transition。
- **代表案例**：电商商品卡、导航菜单、卡片。
- **关键词**：悬停、hover、反馈、预览、过渡

### 9.4 拖拽交互（Drag & Drop）
- **定义**：元素可拖拽移动、排序、放置的交互。
- **视觉特征**：拖拽预览、占位提示。
- **动效特征**：拖拽跟随、排序动画、放置反馈。
- **适用场景**：任务看板、文件管理、表单排序、编辑器。
- **技术实现**：dnd-kit / SortableJS / Framer Motion drag。
- **代表案例**：Trello、Notion、网盘。
- **关键词**：拖拽、drag、drop、排序、看板

### 9.5 手势交互（Gesture Interaction）
- **定义**：滑动、捏合、长按、边缘滑动等触控手势驱动的交互。
- **视觉特征**：手势驱动的界面变化。
- **动效特征**：跟手、滑动、捏合、长按菜单。
- **适用场景**：移动端导航、图片浏览、视频、游戏。
- **技术实现**：Hammer.js / React Native Gesture Handler / iOS 手势。
- **代表案例**：移动端返回手势、图片捏合缩放。
- **关键词**：手势、gesture、滑动、捏合、触控

### 9.6 零界面 / 语音（Zero UI / Voice）
- **定义**：减少传统 UI，用语音、手势、自动化等"隐形交互"替代界面操作。
- **视觉特征**：极简界面或语音波形。
- **动效特征**：语音波形、指令反馈。
- **适用场景**：语音助手、智能家居、车载、无障碍。
- **技术实现**：语音识别 API + 波形动画。
- **代表案例**：Siri、Google Assistant、智能音箱界面。
- **关键词**：零界面、语音、zero UI、voice、隐形交互

## 十、数据可视化动效类

> 核心思想：数据以动态、可理解的方式呈现，讲好数据故事。

### 10.1 数字滚动（Count-up）
- **定义**：数字从 0 或初始值滚动递增到目标值。
- **视觉特征**：数字递增、单位提示。
- **动效特征**：滚动计数、缓动减速。
- **适用场景**：数据展示、KPI 指标、成就页、落地页。
- **技术实现**：CountUp.js / JS 缓动循环。
- **代表案例**：各类数据仪表盘、产品指标展示。
- **关键词**：数字滚动、count-up、计数、指标、缓动

### 10.2 图表动画（Chart Animation）
- **定义**：图表（柱状、折线、饼图）的入场、过渡与实时更新动画。
- **视觉特征**：图表动态绘制。
- **动效特征**：柱状生长、折线绘制、饼图展开、过渡。
- **适用场景**：数据大屏、BI 仪表盘、报告。
- **技术实现**：ECharts / Chart.js / D3.js / Recharts。
- **代表案例**：各类 BI 工具、数据大屏。
- **关键词**：图表、chart、数据可视化、ECharts、D3

### 10.3 数据故事化（Data Storytelling）
- **定义**：用滚动 + 动画引导用户逐步理解数据背后的故事。
- **视觉特征**：数据 + 叙事结合。
- **动效特征**：滚动驱动数据变化、重点高亮。
- **适用场景**：数据报道、年度报告、新闻专题。
- **技术实现**：D3.js + ScrollTrigger / Flourish。
- **代表案例**：纽约时报数据报道、年度报告页。
- **关键词**：数据故事、storytelling、报道、滚动、D3

## 十一、AI 生成式界面类

> 核心思想：AI 实时参与界面生成与自适应，界面"因人而变"。

### 11.1 生成式 UI（Generative UI）
- **定义**：界面由 AI 根据用户意图实时生成/重组，而非预先写死的固定布局。
- **视觉特征**：动态生成的组件与布局。
- **动效特征**：组件流式生成、重组过渡。
- **适用场景**：AI 助手、智能表单、对话式界面。
- **技术实现**：LLM + 组件渲染框架（如 Vercel AI SDK）。
- **代表案例**：ChatGPT、Claude 的交互组件、智能客服。
- **关键词**：生成式 UI、generative UI、AI、动态生成、流式

### 11.2 自适应界面（Adaptive / Personalized UI）
- **定义**：界面根据用户行为、偏好、环境自动调整布局、色彩、内容。
- **视觉特征**：个性化布局与内容。
- **动效特征**：布局平滑重组、主题切换。
- **适用场景**：内容推荐、个性化首页、智能主题。
- **技术实现**：用户行为数据 + 动态布局引擎。
- **代表案例**：Netflix、Spotify、新闻 App 个性化。
- **关键词**：自适应、个性化、adaptive、personalized、推荐

### 11.3 AI 实时渲染 / 动效生成（AI-generated Motion）
- **定义**：AI 生成或辅助生成动效、3D 资产、视频转场。
- **视觉特征**：AI 生成的高质量视觉/动效素材。
- **动效特征**：AI 生成动画、智能补间、风格迁移。
- **适用场景**：原型设计、视频制作、游戏资产、创意生成。
- **技术实现**：生成式模型 + 动效引擎（如 Sora、Runway、Luma）。
- **代表案例**：AI 视频生成、AI 原型工具。
- **关键词**：AI 动效、生成、视频、补间、风格迁移
