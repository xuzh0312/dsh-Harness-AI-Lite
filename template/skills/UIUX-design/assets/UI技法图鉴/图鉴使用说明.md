# UI 技法图鉴

解压后保留原目录结构，直接用现代浏览器打开 [布局图鉴](<布局图鉴.html>) 或 [动效与材质图鉴](<动效与材质图鉴.html>)。无需安装、构建或启动服务。

- 首页先展示容易混淆的对照。点「查全部编号」进入完整目录，可按章节跳转，或搜索编号、中英文术语及分类参考中的适用场景（如「商品列表」「播放控制」）。空格分隔的词须同时命中；输入完整编号 `1.1` 不会同时命中 `1.10`。
- 目录中的「已有对照」跳到对应卡片；其余条目展开才运行示例，收起则重置。布局页的「宽容器 / 窄容器」同时控制对照和目录预览宽度。
- 每个示例的源码对应正在运行的效果。「近似」只复现特征；「示意」说明流程，不等同于原生系统、设备或模型已经接入。
- 先按用户任务和内容找候选：例如商品浏览先比较栅格和列表，播放控制先检查操作反馈是否明确。用真实内容比较宽窄变化或操作前后，再看源码，不照搬演示内容或配色。
- 高频操作、密集信息和长文阅读中，避免会遮挡内容、降低对比度或拖慢操作的材质和动画。响应 `prefers-reduced-motion`：停用非必要的视差、循环和大幅位移，保留即时的文字、图标或状态变化作为反馈。
