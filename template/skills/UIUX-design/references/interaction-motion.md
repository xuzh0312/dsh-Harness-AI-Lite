# 交互与动效

**先写状态，再决定是否要动。** 为操作写一行“触发 → 可见反馈 → 结果或恢复”。只有运动能解释对象来自哪里、什么改变了或下一步在哪里，才加过渡。高频键盘操作应立即可用；一次性的空间切换可以给人时间看清。出现和离开的时长可不同，按目标平台与使用频率试调。

**保证连续。** 弹层从触发点附近出现，关闭时空间关系一致。直接拖动时画面跟随手势；松手按速度与边界决定去向。用户反向拖、再次点击或连续撤销时，从当前画面接续。轻按、慢拖、快速反向各试一次，避免必须等动画结束才能继续。

**用术语说清观察。** “列表逐项出现”可用错开（stagger）描述；“拖过边界后拉回来”叫弹性回弹（rubber-banding）。命名之后再问它是否有用。错开若拖迟最后一个可操作项，就缩短、取消或同时显示；按钮已收到输入时要立即给反馈。

**走查手感与替代。** 检查触发到反馈的延迟、快速重复操作、运动起止位置、掉帧和可中断性。在系统减少动态效果时缩短或去掉大幅位移，保留位置、文字或状态的变化。对依赖时序的交互做小原型，在目标设备实测；静态稿只能说明起止状态。交接触发条件、起止状态、打断与降动效行为，参数有实测依据时再固定。
