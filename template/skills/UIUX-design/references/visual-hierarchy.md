# 排版、色彩与布局

**先决定扫读顺序。** 挑一屏真实内容，让人第一眼找到正在处理的对象，再看到主要操作和结果。用分组、对齐与留白表达关系，边框和卡片只在确有边界时出现。高频工具优先稳定位置和紧凑扫描；长文优先合适栏宽和阅读节奏。

**为角色选字。** 用同一份标题、正文、标签与数字测试字号、字重、行高和字族。两级信息分不清，先拉开真正需要的差异。用长中文标题、中英混排、连续编号和金额检查换行及列对齐；放大字号、缩小窗口或缺少首选字体时仍要找得到主要操作。窄屏优先保住内容与操作的邻近关系。

**给颜色分工。** 选背景、表面、正文、次要文字、主要操作、焦点和状态各自的用途。用实际前景与背景组合检查可读性，包括按钮上的字和禁用之外的次要提示。成功、选中与错误用文字、图标或形状补充。扩大强调色面积之前，先看它是否让两个操作争夺注意力。

**用可见结果收尾。** 用目标尺寸预览，带上长内容、空数据和异常值。让评审者指出第一眼看到什么、实际应当先做什么；两者不一致时先改层级，再调色值。记录一个影响使用的修改及其依据。
